貼上 info hash,立刻得到磁力連結

核心功能

一眼看懂 Magnet Link Generator 能做什麼。

🔐

BTIH 與 BTMH

支援 BitTorrent v1(SHA-1)與 v2(SHA-256)。

🧩

選填欄位

顯示名稱 dn、大小 xl、關鍵字 kt、網頁種子 ws、多個追蹤器 tr。

📡

內建追蹤器

一鍵載入 20 個常用公開追蹤器,不會重複加入。

📋

複製或測試

複製到剪貼簿,或直接用 qBittorrent 開啟。

✅

雜湊驗證

格式異常時會提示,並可選擇仍然繼續。

🌗

淺色／深色

支援兩種色彩配置。
