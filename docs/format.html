Format

連結格式

磁力連結的參數長什麼樣子。

典型格式

BitTorrent v1 的典型磁力連結:

magnet:?xt=urn:btih:<INFO_HASH>&dn=<NAME>&tr=<TRACKER_URL>

參數

參數意義
xt確切主題:urn:btih:(v1)或 urn:btmh:(v2)
dn顯示名稱
xl檔案大小(bytes)
kt關鍵字
ws網頁種子(HTTP/FTP)
tr追蹤器

名稱、網頁種子與追蹤器網址會做百分比編碼。
