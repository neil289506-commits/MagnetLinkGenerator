Usage

使用方式

貼上 info hash、補幾個欄位,按一下就能複製。

操作步驟

啟動程式

開啟 Magnet Link Generator。

選擇雜湊類型

BTIH 或 BTMH。

輸入 info hash

必填。

補充欄位

視需要填寫顯示名稱、檔案大小、關鍵字、網頁種子或追蹤器。

產生

按「產生磁力連結」。

複製或測試

複製連結,或以 qBittorrent 開啟測試。

欄位規則

BTIH40 碼十六進位,或 32 碼 Base32
BTMH十六進位,長度為偶數且至少 4 碼(含前綴)
檔案大小 xl必須是正整數(bytes);格式錯誤時略過此欄位並提示
關鍵字 kt以逗號分隔,輸出時以 + 連接
追蹤器 tr每行一個網址,可有多個
雜湊格式不符預期時會提示,你可以選擇仍然繼續。「測試」功能需要已安裝 qBittorrent,其餘功能不需要。
